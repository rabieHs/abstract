title: Memory
description: How abstract remembers your preferences, style, and project facts, and how you stay in control.
---

abstract keeps **memory notes** for each workspace: short facts that shape every reply. There are
four kinds:

| Kind | Example |
|---|---|
| preference | "Always use IEEE citation style." |
| style | "Short paragraphs; no bullet lists in the main text." |
| project | "The review covers sleep interventions in adolescents." |
| lesson | "The supervisor wants limitations in every chapter." |

## How notes are added

- **You ask.** Say "remember that…", "always…", or "from now on…" and the agent saves the note
  right away.
- **The agent notices.** When it infers a preference you didn't state, it proposes a note that
  **waits for your approval**. Nothing inferred is used until you approve it.
- **You add it yourself** on the **Memory** screen: pick a kind, type the note, click **Add**.

## The Memory screen

- **Pending:** notes the agent proposed. **Approve** or delete them.
- **Active:** notes in use. **Pause** one to stop using it without deleting it, or delete it.

## How notes are used

Active notes are included with every request, each stamped with the month it was saved, so the
agent can tell old from new. If they grow past about 4,000 characters, the oldest are left out,
and the agent is told that some were omitted.

Memory is stored per workspace, inside `.openpaper/` in the workspace folder.
