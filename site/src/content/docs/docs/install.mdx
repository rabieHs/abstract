abstract runs on **macOS** (Apple Silicon and Intel) and **Linux** (x64 and arm64).

## The easy way: one command

<Steps>

1. **Open a terminal.** On a Mac: press <kbd>⌘</kbd>+<kbd>Space</kbd>, type *Terminal*, and press
   <kbd>Enter</kbd>.

2. **Paste this and press Enter:**

   ```bash
   curl -fsSL https://useabstract.co/install.sh | sh
   ```

   It downloads abstract for your computer, checks it, and installs it. Nothing else is needed:
   no Bun, no Node, no admin password.

3. **Open a new terminal window** (so it finds the new command), then check it works:

   ```bash
   abstract --version
   ```

</Steps>

Next: the [quick start](/docs/quick-start/) takes you from an empty folder to a verified draft.

### What the installer does

- Detects your system and downloads the matching file from
  [GitHub Releases](https://github.com/rabieHs/abstract/releases).
- **Verifies its SHA-256 checksum** against the published `SHA256SUMS`. If they don't match, it
  stops and installs nothing.
- Puts the `abstract` command in `~/.local/bin`, and adds that folder to your `PATH` in your shell's
  startup file (`~/.zshrc`, `~/.bashrc`, …) if it isn't there already.

You can read the script first: [useabstract.co/install.sh](https://useabstract.co/install.sh).
Options are set with environment variables:

```bash
# a specific version
curl -fsSL https://useabstract.co/install.sh | ABSTRACT_VERSION=0.2.0 sh
# another folder, without touching your shell files
curl -fsSL https://useabstract.co/install.sh | ABSTRACT_INSTALL_DIR=~/bin ABSTRACT_NO_MODIFY_PATH=1 sh
```

### Where the files come from

Every release is built by [GitHub Actions](https://github.com/rabieHs/abstract/actions) from the
public source code, on GitHub's own machines, not on anyone's laptop. Each file comes with a
**build-provenance attestation**, and you can verify it with the
[GitHub CLI](https://cli.github.com/):

```bash
gh attestation verify abstract-darwin-arm64.tar.gz --repo rabieHs/abstract
```

## For developers: npm or Bun

If you already use [Bun](https://bun.sh) (1.1 or newer), you can install the package instead. This
version runs on your Bun:

<Tabs>
  <TabItem label="Bun">
    ```bash
    bun install -g abstract-cli
    ```
  </TabItem>
  <TabItem label="npm">
    ```bash
    npm i -g abstract-cli   # Bun must still be installed to run it
    ```
  </TabItem>
</Tabs>

## Update

Run the installer again. It replaces the old version and keeps your settings and workspaces:

```bash
curl -fsSL https://useabstract.co/install.sh | sh
```

With npm or Bun: `npm i -g abstract-cli@latest` or `bun install -g abstract-cli@latest`.

Then restart abstract (stop it with <kbd>Ctrl</kbd>+<kbd>C</kbd> and run `abstract` again).

## Uninstall

```bash
rm ~/.local/bin/abstract        # installed with the installer
npm uninstall -g abstract-cli    # or with npm / bun remove -g abstract-cli
```

This removes the program only. Your data stays where it is: settings, keys, and skills in
`~/.abstract`, and each workspace in its own folder. Delete those yourself if you want them gone,
and remove the `# added by the abstract installer` line from your shell's startup file.

:::note[Windows]
Windows isn't supported directly. Running abstract inside WSL (Linux on Windows) may work, but it
isn't tested.
:::

:::tip[Upgrading from an early build]
Settings used to live in `~/.openpaper`. The first time a new version starts, it moves that
folder to `~/.abstract` for you and prints `moved your settings from ~/.openpaper to …`.
:::
