abstract runs on **macOS and Linux** and needs **[Bun](https://bun.sh) 1.1 or newer** — the
`abstract` command runs on Bun even if you install it with npm.

<Steps>

1. **Install Bun** (skip this if `bun --version` already works):

   ```bash
   curl -fsSL https://bun.sh/install | bash
   ```

   Open a new terminal afterwards so the `bun` command is found.

2. **Install abstract:**

   <Tabs>
     <TabItem label="Bun">
       ```bash
       bun install -g abstract-cli
       ```
     </TabItem>
     <TabItem label="npm">
       ```bash
       npm i -g abstract-cli
       ```
     </TabItem>
   </Tabs>

3. **Check it works:**

   ```bash
   abstract --help
   ```

   You should see the usage text. The package is called `abstract-cli`; the command is `abstract`.

</Steps>

Next: the [quick start](/docs/quick-start/) walks you from an empty folder to a verified draft.

## Update

Install the latest version over the old one:

```bash
bun install -g abstract-cli@latest   # or: npm i -g abstract-cli@latest
```

Then restart abstract (stop it with <kbd>Ctrl</kbd>+<kbd>C</kbd> and run `abstract` again).
Your settings and workspaces are kept.

## Uninstall

```bash
bun remove -g abstract-cli   # or: npm uninstall -g abstract-cli
```

This removes the program only. Your data stays where it is: settings, keys, and skills in
`~/.abstract`, and each workspace in its own folder. Delete those yourself if you want them gone.

:::note[Windows]
Windows isn't supported directly. Running abstract inside WSL (Linux on Windows) may work, but it
isn't tested.
:::

:::tip[Upgrading from an early build]
Settings used to live in `~/.openpaper`. The first time a new version starts, it moves that
folder to `~/.abstract` for you and prints `moved your settings from ~/.openpaper to …`.
:::
